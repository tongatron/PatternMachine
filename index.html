Kit SP-1200

42 one-shot di batteria elettronica (WAV, 44,1 kHz/16 bit, mono), mappati per la Drum Machine Designer di Logic Pro, più il plugin Audio Unit Twelve che ricrea il carattere del convertitore a 12 bit / 26 kHz della E-mu SP-1200.

Samples — 44,1 kHz / 16 bit

I 42 file così come preparati: rinominati, mono, normalizzati. Nessun carattere lo-fi aggiunto — il timbro è quello originale dei campioni sorgente.

Plugin Twelve (sorgenti)

Audio Unit aufx per macOS che emula la catena del convertitore SP-1200 (drive, anti-alias, quantizzazione senza dither, ricostruzione, filtro risonante). cd Plugin && ./build.sh compila, firma e installa.
