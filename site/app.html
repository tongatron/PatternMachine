The macOS build is for Apple Silicon; Windows and Linux are x64 builds. All three work offline and include virtual MIDI where the system supports it.

Install

  1. macOS: open the zip and drag PatternMachine into the Applications folder. This version is not notarized by Apple: if macOS refuses to open it the first time, open Terminal, run xattr -dr com.apple.quarantine /Applications/PatternMachine.app and launch the app again. Alternatively, Ctrl-click the app, choose Open and confirm.
  2. Windows: run the .exe installer and follow the wizard. If SmartScreen shows Windows protected your PC, check that the file came from this page, choose More info and then Run anyway.
  3. Linux: download the AppImage, make it executable with chmod +x PatternMachine*.AppImage and run it. If your distribution reports that FUSE is missing, install the FUSE package it requires and try again.

These warnings appear because the packages are not yet signed with a commercial certificate for each operating system. Only accept the installation if you downloaded the file from this private page.

Connecting it to the DAW

  • MIDI notes: in the app's DAW panel leave "MIDI output" on, with General MIDI notes. In the DAW create a drum track and select the "PatternMachine" port.
  • Clock: in the DAW, enable sending MIDI Clock to "PatternMachine". In the app select the DAW, turn on "Follow the DAW clock" and press Play in the DAW.
  • Dragging: grab ⠿ MIDI or ⠿ WAV in the DAW panel and drop it on the timeline. It follows the Pattern/Song selector.
  • Sound from Logic only: turn off "Internal sound".
