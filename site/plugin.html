What it does

  • Automatic sync: Play, Stop, tempo and tempo changes come from Logic. Step 1 lands on bar 1; it also follows cycles and jumps on the ruler.
  • Pattern or Song: in the Grid the selected pattern loops, aligned to the bars; in the Sequencer the song starts at Logic's bar 1 (silent during the pre-roll) and loops at the end.
  • Audio in Logic's mixer: effects, faders, automation and bounces (offline too), as with any instrument.
  • One channel per instrument in Logic: duplicate the plug-in instance and assign each one a row from the Instance menu, so kick, snare, hi-hat and percussion get separate mixer channels.
  • Multiple channels in Logic: duplicate the plug-in instance and assign each one a single row from the Instance menu; each instrument then gets its own mixer channel.
  • The project is saved inside the Logic project and plays even with the window closed.
  • Pads and MIDI keyboard: note C1 (36) plays row 1, C#1 row 2 and so on, so a controller's pads work right away.
  • All the kits, per-step parameters, the library and the site's exports. Projects in Music › PatternMachine › Progetti (the same as the app), exports in Music › PatternMachine › Export: the Export ↗ button next to Play opens the folder.

Installing

  1. Open the zip and copy PatternMachine.component to ~/Library/Audio/Plug-Ins/Components (in the Finder: Go › Go to Folder…). For other DAWs there is also PatternMachine.vst3, to copy to ~/Library/Audio/Plug-Ins/VST3.
  2. The plug-in isn't notarized by Apple: in Terminal run xattr -dr com.apple.quarantine ~/Library/Audio/Plug-Ins/Components/PatternMachine.component
  3. Reopen Logic. If you can't find it: Logic Pro › Settings › Plug-in Manager › Reset & Rescan Selection.

Using it

  1. Track › New Software Instrument Track.
  2. In the channel strip, click the Instrument slot and choose AU Instruments › Tongatron › PatternMachine › Stereo. It helps to rename the track "PatternMachine".
  3. To split the instruments in Logic, duplicate the track, open PatternMachine in each instance and choose the row from the Instance menu next to the Logic badge.
  4. Write the pattern in the plug-in window and press Play in Logic. The BPM field shows Logic's tempo; the badge next to Play reads Logic ▶ pattern or Logic ▶ song.
  5. With Logic stopped, the window's Play button previews at the project tempo. To record audio, use Logic's bounce; for MIDI, use Export › MIDI and drag the file into Logic.
  6. To reopen the window: select the track and click the PatternMac slot.

Apple Silicon Macs only (macOS 12 or later). Per-instance mode uses one stereo output per Logic channel, 6 dB below the site's level to leave headroom in the mixer. Custom kits imported into the app aren't included.
